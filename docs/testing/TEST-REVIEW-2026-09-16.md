- 13 个消费分类均可通过真实 UI 新增；消费与独立里程均覆盖新增、修改、删除、回收站恢复、再次删除和单项永久删除。

- Excel 通过物理触控下载，核对为有效工作簿且包含六张表；本地 CSV 导出入口也已验证。
- 版本、静态资源缓存和 Service Worker 使用同一语义化版本；数据库 schema 版本未因本轮改动变化。
