# V3.1 页面修复（资源版本 v35）

## 范围

- 外屏首页行程入口、路线和进度样式；常用按钮至少 48×48 CSS 像素。
- 720–991px viewport 使用 88px 导航栏及实际双栏；窄账单卡内部重排标题、导出、正文和操作，避免挤压。
- 里程编辑立即打开弹层；关闭编辑后新增不会残留原记录目标。
- 修复异步保存后访问失效事件对象，以及带秒时间无法通过表单校验。
- 待处理查看与待处理导出分开；统计页直接打开里程输入。
- 弹层滚动锁、关闭焦点恢复、可见控件焦点循环、关闭时 inert；Escape 保留草稿。
- 结束里程按钮按已知最大里程、确认框和待同步队列校验。
- HTML、CSS/JS 请求与 Service Worker 缓存版本统一为 v35。
